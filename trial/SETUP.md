# 実証用セット（試用版）セットアップ手順

麻生情報システムでの実地検証用に、**記録が生徒用スプレッドシートとは別のブックに届く**状態を作ります。
アプリ本体は生徒用と同一のものを使うので、検証結果はそのまま本番の評価になります。

- 入口： https://kenjiintasmania.github.io/kenjiyamada/trial/
- 生徒用のGAS・スプレッドシート・URLは **一切変更しません**。

---

## 全体像

```
[実証用の端末] --?site=aso--> 同じアプリ --> 試用版GAS --> 実証用スプレッドシート
[生徒の端末]   （素のURL）  --> 同じアプリ --> 生徒用GAS --> 生徒用スプレッドシート（無改変）
```

切り替えは `assets/site.js` の1か所だけで完結します。実証モードで送信先が未設定のときは
**送信そのものを止める**ので、実証データが生徒用ブックへ落ちることは構造的に起こりません。

---

## 手順（先生・約10分）

### 1. 実証用スプレッドシートを作る

Google ドライブで**空のスプレッドシート**を新規作成します（名前は「英語アプリ 実証ログ（麻生）」など）。
URL の次の部分がシートIDです。コピーしておきます。

```
https://docs.google.com/spreadsheets/d/【ここがシートID】/edit
```

タブは作らなくて構いません（「成績まとめ」「英検テスト履歴」は自動で作られます）。

### 2. 試用版GASを貼る

1. そのスプレッドシートで ［拡張機能］→［Apps Script］ を開く
2. エディタの中身を消して、`tools/score_gas_trial.gs` の**全文**を貼り付け
3. 冒頭付近の2か所を編集して保存

```js
var TRIAL_SPREADSHEET_ID = "【手順1でコピーしたシートID】";
var TEACHER_PIN = "【実証用の合言葉。生徒用とは別の値に】";
```

> **安全弁**：`TRIAL_SPREADSHEET_ID` が空のとき、または生徒用ブックのIDと同じときは、
> このスクリプトはエラーを返して**書き込みを行いません**。取り違えても生徒用ブックは汚れません。

### 3. ウェブアプリとしてデプロイ

［デプロイ］→［新しいデプロイ］→ 種類「ウェブアプリ」

| 項目 | 設定 |
|---|---|
| 次のユーザーとして実行 | 自分 |
| アクセスできるユーザー | **全員** |

デプロイすると `https://script.google.com/macros/s/…/exec` が出るのでコピーします。
初回は権限の承認を求められるので許可してください。

### 4. アプリ側に送信先を貼る

`assets/site.js` の `TRIAL_GAS` に、手順3のURLを**2か所とも**貼ります（同じURLでOK）。

```js
var TRIAL_GAS = {
  summary: "https://script.google.com/macros/s/…/exec",   // マイページ・模試
  eiken:   "https://script.google.com/macros/s/…/exec"    // 英検アプリ
};
```

`master` に push すると数分で GitHub Pages に反映されます。

### 5. 動作確認

1. https://kenjiintasmania.github.io/kenjiyamada/trial/ を開く
2. 「実証用の送信先」が**設定ずみ**になっていることを確認
3. 「接続テスト（書き込みなし）」を押す → `✓ 実証用シートに接続できました（版 trial-…／シート名「…」）`

版が `trial-` で始まらない場合は生徒用GASのURLを貼っています。手順3のURLを貼り直してください。

## つまずいたとき

### 403 が出る（いちばん多い）

**403 はスクリプトの誤りでは出ません。デプロイの公開設定が原因です。**
`score_gas_trial.gs` を貼り直しても直らないので、次を確認してください。

| 確認 | 直し方 |
|---|---|
| アクセスできるユーザーが「全員」以外 | ［デプロイ］→［デプロイを管理］→ 鉛筆 →**アクセスできるユーザー＝全員**→ バージョン「新バージョン」→ デプロイ |
| URLの末尾が `/dev` | `/dev` は**本人ログイン専用**で必ず403。［デプロイを管理］に出る **`/exec`** のURLを使う |
| 学校・会社のアカウントで「全員」が選べない | 組織のポリシー制限。**個人のGoogleアカウントでデプロイし直す**のが手早い回避策 |
| 設定を直したのに変わらない | 「新バージョン」にせず再デプロイすると旧版のまま。必ずバージョンを**新バージョン**に |

**確かめ方**：`/exec` のURLを**ブラウザで直接ひらく**（GETすると `doGet` が応答します）。

- `{"result":"ok","message":"score_gas alive","ver":"trial-…"}` が出る → 公開設定はOK
- ログイン画面・「承認が必要です」が出る → 上の表のとおり公開設定が原因
- 版が `trial-` で始まらない → 生徒用GASのURLを見ています。貼り直してください

`trial/` の「接続テスト」も、これらを判別して原因を画面に出します。

### 初回の承認

初めてデプロイするとき「このアプリは Google で確認されていません」と出ることがあります。
［詳細］→［（プロジェクト名）に移動］→ 許可、で進めてください（自分のスクリプトなので問題ありません）。

### 「TRIAL_SPREADSHEET_ID を確認してください」と返る

公開設定はOKで、GAS側の書き込み先が未設定／生徒用ブックと同じ／開く権限がない、のいずれかです。
安全弁が働いて**書き込みを止めている**状態なので、生徒用ブックは汚れていません。

## 検証シナリオ（実証当日）

1. `trial/` から各アプリを開く（画面上部に 🧪 の帯が出ていることを確認）
2. 単語を数問クリア → 英検の判定テストを1回 → 模試を1本採点
3. マイページで学年（例：3）・番号（例：99）を入力 → 自動送信
4. **実証用ブック**に行が増えることを確認
5. **生徒用ブック**に行が増えて**いない**ことを確認 ← 分離の検証

記録が実際に送信されるのは次の3つだけです。

| 操作 | 送信先タブ |
|---|---|
| マイページ「先生に送信」 | 成績まとめ |
| 英検アプリ 結果送信 | 英検テスト履歴 |
| 模試の単元テスト提出 | 単元テスト |

単語アプリ・読解道場・挑戦モードの記録は端末内（localStorage）に留まります。

## モードの切り替えと解除

| やりたいこと | 方法 |
|---|---|
| 実証モードにする | URLに `?site=aso` を付けて開く（`trial/` の各リンクは付与済み） |
| いま実証モードか確認 | 画面上部に 🧪 の帯が出ていれば実証モード |
| 通常モードに戻す | 帯の「通常モードにもどす」／ `trial/` の解除ボタン／ URLに `?site=school` |
| 自動で戻る | 実証モードは **60日で自動失効**（戻し忘れ対策） |

> 実証モードは端末（ブラウザ）単位で記憶されます。生徒の端末で `?site=aso` を開くと
> その端末の記録が実証側に行くため、実証には**貸出端末や検証用プロファイル**を使ってください。

## 先生用コンソール

`/admin/?site=aso` を開くと、実証用ブック側の単元テストゲート・学習方針を操作できます。
合言葉は手順2で設定した**実証用のPIN**です。画面上部の版表示が `trial-…` になっていることが、
実証側を見ている確認になります。
