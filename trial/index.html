③ 検証の進めかた（推奨シナリオ）

  1. 単語アプリで数問クリア → 英検アプリで判定テストを1回 → 模試を1本採点
  2. マイページを開き、学年（例：3）と番号（例：99）を入れる → 自動送信が走る
  3. 実証用スプレッドシートの「成績まとめ」「英検テスト履歴」に行が増えることを確認
  4. 生徒用スプレッドシートに行が増えていないことを確認（分離の検証）
実証中の記録は学年・番号のみで識別されます。氏名欄は任意で、空でも送信できます。

④ 先生（管理者）の初期設定

  1. 実証用の空のスプレッドシートを新規作成する
  2. ［拡張機能］→［Apps Script］に tools/score_gas_trial.gs を全文貼り付け
  3. TRIAL_SPREADSHEET_ID に①のシートIDを貼る（生徒用IDだと安全弁で停止します）
  4. ウェブアプリとしてデプロイし、/exec のURLを assets/site.js の TRIAL_GAS に貼る
  5. このページの「接続テスト」で ✓ になれば準備完了
詳細な手順は trial/SETUP.md。生徒用のGAS・スプレッドシートは一切変更しません。
